Addition operator for two vec3d objects, performed by the addition of each corresponding component

b = vec3d()

a.set_xyz( 1.0, 2.0, 3.0 )
b.set_xyz( 4.0, 5.0, 6.0 )

c = a + b

print( "a + b = ", False )

print( c )
