# Official reference builds

This directory contains unmodified official OpenVSP binary distributions used
for parity and regression checks while changing the VSPAERO sources.

## OpenVSP-3.51.2-win64

- Version: OpenVSP 3.51.2
- Platform: Windows x64
- Python: 3.13
- Origin: official distribution supplied locally by the repository owner
- Imported: 2026-08-23

Keep this reference build unchanged. New experimental binaries belong in the
normal ignored build directories, not in this folder.
